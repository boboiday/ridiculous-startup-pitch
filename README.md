Entry for **Ridiculous at First Glance, Real by the Second** — one single-sentence startup pitch, so strange it sounds like a joke, yet specific enough that you can see the customers and the money:

> We sell naming rights for potholes, so brands pay $99 a month to sponsor the crater outside their rival's office while the city gets free repairs.

## Run it

```sh
node main.ts   # writes the pitch to /output/entry.txt
```

Deterministic: the sentence is fixed, no randomness, no clock, no network.
